# 2족보행 로봇 개념 모델 v3 (모터 12개, Inventor용 STEP)

`biped_robot_v3.stp`는 설계안 v3의 치수로 만든 STEP AP214 어셈블리입니다. 구성은 다음과 같습니다.

- **다리**: 다리당 4축(고관절 피치, 무릎, 발목 피치, 발목 롤)
- **결합 고관절 요**: 모터 1개로 두 다리의 요를 반대 방향으로 돌림
- **팔**: 양쪽 어깨 피치 1축씩
- **머리**: 팬 1축과 소형 카메라

서보는 외형 크기 블록이고, 혼 축은 ROBOTIS 도면대로 본체 끝에서 11.25 mm 위치입니다. 3D 프린트 부품은 연결 관계를 나타낸 단순한 형상이므로, 실제 출력 형상은 이 배치를 기준으로 Inventor에서 다듬으세요.

## 좌표와 자세

- 단위는 mm이고, X가 앞, Y가 왼쪽, Z가 위입니다. 원점은 두 발 사이 바닥입니다.
- 다리를 곧게 펴고 팔을 내린 영점 자세입니다. 전체 크기는 X −65~60, Y −101~101, Z 0~405 mm입니다.
- 관절 각도의 부호는 관절축(+X, +Y, +Z) 기준 오른손 법칙을 따릅니다.

## 어셈블리 구조 (하위 어셈블리 15개 = 강체 15개)

| 하위 어셈블리 | 들어 있는 부품 |

| `R_/L_hip_yaw_link` | 고관절 피치 서보(XC430), 요 브래킷(보스, 서보를 잡는 앞뒤 벽, 레버, 핀) |
| `R_/L_thigh` | 무릎 서보(XM430), 허벅지 프레임(한 덩어리) |
| `R_/L_shank` | 발목 피치 서보(XM430), 정강이 프레임(한 덩어리) |

## Inventor에서 여는 방법

1. **파일 → 열기**에서 `biped_robot_v3.stp`를 고르고, 가져오기 옵션에서 **변환(Convert Model)** 을 선택합니다.
2. `torso`를 고정(Grounded)합니다.
3. **관절 걸기**: 관절마다 원형 요소 두 개를 골라 **삽입(Insert) 구속조건**을 겁니다. Dynamic Simulation 설정에서 "구속조건을 표준 조인트로 자동 변환"을 켜면 회전 조인트로 바뀝니다.
   - **피치·롤 관절, 머리, 어깨**: 빨간 디스크 두 개(부모 지름 20 mm, 자식 지름 16 mm)를 씁니다.
   - **고관절 요**: 요 브래킷의 보스(지름 25 mm)와 베어링 안쪽 구멍을 씁니다.
   - **결합 막대**: 막대 양 끝 구멍과 레버 핀을 씁니다.
4. **결합 막대의 과구속 경고**: 막대가 닫힌 고리를 만들어 Dynamic Simulation에서 과구속 경고가 날 수 있습니다. 그때는 `tie_rod`를 억제하고, 왼쪽 요 관절에 오른쪽과 반대 부호의 동작을 직접 주세요.
5. **질량 입력**: 출력물과 전자 부품은 속이 꽉 찬 블록이라 재료 밀도로 계산하면 질량이 틀립니다. iProperties → 물리적 특성에서 아래 표의 값으로 지정하세요. 볼트·너트·베어링·핀은 강철 재질로 두면 형상대로 계산됩니다.
6. **서보 교체(선택)**: ROBOTIS e-Manual 도면 항목에서 받은 XC430·XM430 STEP으로 **구성요소 대치(Replace Component)** 합니다.

## 검증과 한계

- **검증 내용**: 생성 후 STEP을 다시 읽어 확인했습니다.
  - 참조 누락과 B-rep 모서리 방향 오류가 없습니다.
  - 솔리드 163개가 모두 의도한 위치에 있습니다.
  - 원통과 판의 관통 구멍까지 고려한 정밀 검사에서, 서로 다른 링크 사이 간섭이 없습니다.
  - 링크 안에서 볼트는 구멍으로만 지나갑니다.
  - 검사기가 일부러 넣은 충돌을 잡아내는지도 확인했습니다.
  - Inventor에서 직접 열어 보지는 못했으므로, 가져오기에서 오류가 나면 알려 주세요.
- **형상 한계**: 브래킷과 링크는 연결 관계와 대략적인 공간만 나타냅니다. 서보 고정 나사 구멍(M2, M2.5)은 넣지 않았습니다. 실제 서보 STEP으로 바꾼 뒤 그 구멍에 맞춰 뚫으세요.
- **시뮬레이션**: Inventor Dynamic Simulation은 관절 토크와 간섭을 확인하는 데 쓰고, 보행과 강화학습은 같은 치수의 MJCF로 MuJoCo 등에서 하세요. 이때 결합 요는 등식 구속(왼쪽 = −오른쪽)으로 표현합니다.
