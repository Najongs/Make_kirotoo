# 2족보행 로봇 v8 — 출력·조립 가이드 (KIRO 마스코트에 더 가깝게, 나사 없이 조립)

v8은 v7의 조립 방식(출력물끼리 나사 없이 끼움)을 그대로 두고, 마스코트 그림에 맞춰 외형을 고친 버전입니다. 가슴의 KIRO 로고는 나중에 스티커로 붙이므로 모델에 넣지 않았습니다.

## 0. v8 외형 변경 (v7 대비)

| 부위 | v7 | v8 (마스코트 그림 기준) |
| --- | --- | --- |
| 머리 | 200×150, 모서리 R50 | **200×170, 모서리 R70**. 더 둥글고 키가 큼. 머리 바닥 높이는 그대로라 목 관절 여유는 같음 |
| 얼굴 테두리 | 얼굴판이 8 mm 들어가 있고 안쪽이 보임 | 앞쪽 **24 mm 45° 베벨**이 하늘색 테두리가 되고, 흰 얼굴판(149×119)이 테두리와 **같은 면** |
| 눈 | 18×36, 간격 ±34 | **20×40, 간격 ±37.5**, 얼굴 가운데 높이 |
| 입 | 작은 호(폭 30 mm) | **넓고 얕은 미소 선**(폭 약 39 mm, 굵기 5 mm) |
| 볏 | 앞쪽 작은 상자(44×68×26) | **앞뒤로 긴 낮은 등줄기**(91×54×18), 걸쇠 4개 |
| 귀 | 두께 18, 하늘색 원판 Ø38 | **두께 22, 원판 Ø44** |
| 안테나 | 95 mm(머리 위로 높이 솟음) | **60 mm**, 귀 바깥쪽으로 4 mm 이동 |
| 팔 | 긴 소매 + 작은 손(Ø35) | **짧은 소매 + 큰 손(Ø40)** |
| 반바지 | 높이 20 mm | **30 mm**(필라멘트 교체 높이 30 mm) |

- **얼굴판 고정:** 얼굴판이 테두리와 같은 면에 오면서 고정 방식이 바뀌었습니다. 위아래 베벨 안쪽의 45° 리브 4개가 얼굴판 뒤를 받치고, 양옆의 긴 걸쇠 2개(두께 2 mm, 길이 31 mm)가 머리 안 걸림 바에 걸립니다.
- **카메라:** 왼쪽 눈 뒤, 눈 인서트의 9×9 mm 창에 그대로 있습니다.
- **그대로 둔 차이:**
  - 몸통이 머리보다 많이 좁은 마스코트 비율은 따라가지 못했습니다. 다리 간격(±40 mm)과 요 서보 때문에 몸통 폭 150 mm보다 좁힐 수 없습니다.
  - 머리 아래 목이 27 mm 보입니다. 틸트 ±20° 때 머리가 몸통에 닿지 않게 하려면 이 틈이 필요합니다.
- **무게와 크기:** 출력물은 v7보다 약 26 g 늘었습니다. 키는 안테나·볏 끝까지 55.3 cm입니다.

- `print_parts/parts.json`: 아래 부품표의 원본 데이터
- `biped_v8_preview.png`, `biped_v8_inside.png`: 외관과 내부(커버를 뺀 상태) 그림

## 2. 끼워 맞춤 방식과 공차

| 방식 | 쓰는 곳 | 치수 |
| --- | --- | --- |
| 스냅 걸쇠 | 덮개, 얼굴판, 볏, 귀 | 팔 두께 1.6 mm, 걸림 1.0 mm, 45° 들어감·45° 빠짐. 길이 14–28 mm라 휨 변형률 약 1.2% 이하(PLA 안전 범위) |
| 더브테일 레일 | 몸통 커버 | 한쪽 틈 0.2 mm(미끄럼 끼움). 홈 위쪽이 막혀 있어 커버가 레일 위에 걸림 |
| T-레일 + 혀 걸쇠 | 팔 | 목 3.6 mm, 머리 7 mm, 슬롯 4 mm. 혀(1.2 mm 두께, 길이 22 mm)의 돌기가 팔 키홀에 들어감 |
| 빔 걸쇠 | 허벅지·정강이 셸 | 빔 1.2 × 7.6 × 14 mm, 돌기 1.0 mm가 프레임 앞면 홈(깊이 2 mm)에 들어감 |
| 압입 | 선반 핀(Ø3.0), 눈·입 인서트, 귀 원판(Ø16), 안테나(Ø8), 손 링, 카메라 핀(Ø2.0) | 모델은 0 공차(맞닿음). 실제 출력물은 구멍이 0.1–0.2 mm 작게 나오므로 보통 빡빡하게 들어갑니다 |

- **먼저 시험 출력:** `camera_clip`과 `shelf_pins`를 먼저 출력해 압입 정도를 확인하세요.
  - 너무 빡빡하면 슬라이서의 구멍 보정(X-Y hole compensation)을 +0.05~0.1 mm로 하거나 사포로 다듬습니다.
  - 헐거우면 순간접착제를 한 방울 씁니다.
- **걸쇠 출력 방향:** 걸쇠 팔은 대부분 세워져 출력되어 층 방향으로 휩니다. 벽 3줄 이상, 노즐 온도는 권장 범위의 위쪽(PLA 215 °C 안팎)으로 하면 층간 접착이 좋아집니다. 걸쇠가 부러지면 터틀봇3 키트의 플라스틱 리벳으로 임시 고정할 수 있습니다.
- **분해:** 모든 걸쇠는 빠지는 쪽도 45°라서 세게 당기면 빠집니다.
  - 얼굴판은 테두리와 같은 면이라 손으로 잡기 어렵습니다. 머리를 떼어 낸 상태에서 아래 목 구멍으로 긴 드라이버를 넣어 양옆 걸쇠를 안쪽으로 누르면서 앞으로 밀어냅니다.
  - 덮개는 목 아래를 잡고 위로 당깁니다.
  - 팔은 위로 밀어 올립니다.

## 3. 출력 설정 (PLA, 0.4 mm 노즐)

v6와 같습니다.

- 층 높이 0.2 mm, 서포트 없음
- 구조 부품: 벽 3줄 이상, 채움 30% 자이로이드
- 셸: 모델 두께 그대로(채움 100%)

38개 부품 모두 아래 표의 방향에서 서포트가 0으로 나왔습니다. 검사 기준은 다음과 같습니다.

- 45° 규칙
- 양쪽이 받쳐진 30 mm 이하 브리지는 허용
- 한쪽만 받쳐진 3 mm 이하 돌출은 허용

## 5. 구매·재활용 부품 (터틀봇3 버거 키트에서 쓸 수 있는 것)

| 키트 부품 | 쓰임 |
| --- | --- |
| OpenCR 1.0 | 메인 서보 제어기. TTL 포트 3개 = 왼다리·오른다리·머리 체인 |
| Li-Po LB-012 (11.1 V 1800 mAh, 88×35×26 mm, 106 g, 5C) | 몸통 배터리 자리에 맞춤 |

| USB 케이블 | Jetson ↔ OpenCR |
| DYNAMIXEL–OpenCR 케이블 ×2 | 체인 시작 케이블. 나머지는 서보에 딸려 오는 케이블 사용 |
| XL430-W250 ×2 | **머리 팬·틸트에 XC430 대신 쓸 수 있습니다**(아래 참고) |
| M2.5 나사·너트 | 서보 케이스 고정용으로 쓸 수 있음. 길이는 공식 STEP 반영 후 확정 |
| 플라스틱 리벳 | 걸쇠가 부러졌을 때 임시 고정 |
| Raspberry Pi 3 전원 케이블 | 구형 Jetson Nano(B01)라면 OpenCR 5 V → 마이크로 USB(5 W 모드) 전원으로 쓸 수 있음. Orin Nano에는 안 맞음 |

필요 없는 것은 와플 플레이트, 바퀴·타이어, 볼 캐스터, LDS, 플레이트 서포트, M3 나사·너트, Raspberry Pi 3입니다.

**XL430을 머리에 쓸 때:**
- XL430은 XC430과 몸체 크기(28.5×46.5×34 mm)와 통신 방식(TTL, 프로토콜 2.0)이 같아서 모델을 바꿀 필요가 없습니다.
- 토크와 기어 강도는 XC430보다 낮지만, 머리 팬·틸트의 정하중은 작아서 충분합니다.
- 케이스 나사 구멍 위치는 XL430 공식 STEP으로 확인한 뒤 뚫겠습니다.
- 터틀봇에서 쓰던 ID(1, 2)는 다리 서보와 겹치지 않게 DYNAMIXEL Wizard로 바꾸세요.

**전원:**
- OpenCR의 12 V 출력은 최대 4.5 A이고, 12 V와 5 V 출력을 합쳐 55 W를 넘지 않아야 합니다.
- 처음 서기·머리 실험은 OpenCR을 거쳐도 됩니다.
- 보행 실험부터는 배터리 → 전원 분배(예: ROBOTIS 전원 허브) → 각 체인으로 서보 전원을 따로 주고, OpenCR은 통신만 맡기는 구성을 권합니다.

## 6. 조립 순서

**다리 (한쪽씩)**
1. 발판의 브래킷 세로판에 발목 롤 서보 혼을 체결합니다(서보 나사). 발목 롤 서보는 발목 브래킷 뒤판에 고정합니다.
2. 발목 피치 서보를 정강이 프레임에 끼우고, 발목 브래킷 측판을 혼과 아이들러에 체결합니다.
3. **정강이 셸:** 정강이 프레임 위쪽에서 셸을 씌워 내립니다. 셸 안쪽 받침 걸이가 프레임 앞면 받침에 앉을 때, 빔 돌기가 프레임 홈에 딸깍 들어갑니다. **무릎을 연결하기 전에** 합니다.
4. 무릎 서보를 허벅지 프레임에 끼웁니다. **허벅지 셸**도 같은 방식으로 위에서 씌워 내린 뒤, 정강이 측판을 무릎 혼과 아이들러에 체결합니다.
5. 고관절 피치 서보와 요 브래킷을 체결합니다.

**몸통**
1. 프레임에 6805 베어링 2개를 압입합니다. 요 서보를 위에서 넣어 골반판에 고정하고(서보 나사), 요 브래킷 보스를 베어링에 끼워 혼에 체결합니다.
2. 배터리를 앞에서 넣습니다. 선반을 앞에서 받침 위로 밀어 넣고, 핀 4개를 위에서 눌러 끼웁니다. Jetson과 DC-DC 컨버터, IMU를 선반에 올립니다.
3. **OpenCR:** 프레임 뒷벽 모서리 홈 4곳에 보드를 위에서 밀어 넣습니다. 보드 아래는 홈 바닥에, 위는 나중에 덮개 캡에 막힙니다. 홈은 보드 모서리 3 mm만 덮습니다.
4. **커버:** 앞·뒤 커버를 위에서 내려, 안쪽 더브테일 홈을 측벽 레일에 끼웁니다(한쪽에 2개씩). 홈 위쪽이 레일 끝에 걸리면 멈춥니다.
5. 팬 서보를 덮개에 고정합니다(서보 나사). **덮개**를 위에서 눌러 걸쇠 4개가 측벽 창에 들어가게 합니다. 캡이 커버 윗단과 OpenCR을 함께 막습니다.
6. **팔:** 팔을 15 mm 정도 올린 위치에서 키홀을 앞 커버의 T-레일 머리에 맞춰 붙입니다. 그대로 내리면 레일 목이 슬롯으로 들어가고, 키홀이 커버 혀의 돌기에 오면 딸깍 걸립니다. 그다음 손을 소매 아래에 눌러 끼웁니다.

**목·머리**
1. 목 기둥을 팬 서보 혼에 체결하고, 틸트 서보를 목 기둥에 고정합니다(서보 나사).
2. **카메라:** 얼굴판 뒤 기둥 4개의 핀에 Pi 카메라 보드를 렌즈가 눈 쪽을 향하게 꽂고, `camera_clip`을 뒤에서 눌러 끼웁니다. 눈·입 인서트를 앞에서 압입합니다(`eye_L`은 렌즈 창이 있는 쪽).
3. **볏:** 볏 걸쇠 4개를 머리 윗벽 슬롯에 맞춰 누릅니다. **귀:** 귀 걸쇠 2개를 옆벽 슬롯에 맞춰 누릅니다. 귀 원판과 안테나를 압입합니다.
4. 머리를 위에서 내려 틸트 서보가 바닥 구멍을 지나게 합니다. 머리 안 프레임 판 2장이 서보 양옆에 오면, 열린 앞면으로 손을 넣어 혼과 아이들러를 체결합니다.
5. 카메라 FFC 케이블을 머리 바닥 구멍으로 빼서 목에 한 바퀴 느슨하게 감고 몸통 안 Jetson으로 보냅니다.
   - 구형 Jetson Nano(B01)는 15핀 커넥터라 Pi 카메라 케이블을 그대로 씁니다.
   - Orin Nano는 15→22핀 케이블이 필요합니다.
6. 얼굴판을 앞에서 눌러 넣습니다. 뒷면이 위아래 리브에 닿고 양옆 걸쇠가 걸림 바 뒤에 걸리면, 얼굴판 앞면이 하늘색 테두리와 같은 면이 됩니다.

## 7. 검증과 한계

**검증 결과:**
- 전체 STEP과 부품별 STEP 38개를 다시 읽었고(v8 기준), 참조와 모서리 오류가 없습니다. 솔리드 위치는 0.05 mm 안에서 모델과 맞습니다.
- 링크 사이 간섭은 0건입니다. 자세를 바꿔 가며 검사(머리 팬×틸트, 다리 관절 조합)해도 0건입니다.
- 같은 링크 안 부품끼리도 걸쇠·슬롯·창·레일·핀이 서로 파고들지 않는 것을 검사했습니다. 남은 2건은 베어링 압입(의도한 접촉)입니다.
  - 이 검사가 실제로 걸러내는지 확인하려고, 창을 없앤 벽에 덮개 걸쇠를 대 보았고 충돌로 잡혔습니다.

**한계:**
- **걸쇠 강도는 실물로 확인해야 합니다.** 치수는 PLA 일반 설계값(변형률 2% 이하)으로 잡았습니다. 하지만 층 방향, 프린터, 필라멘트에 따라 달라지므로, 처음에는 하나씩 시험해 보세요.
- **OpenCR 홈:** OpenCR 장착 구멍 좌표가 공개 자료에 없어서, 모서리 홈은 보드 외곽(105×75)만 기준으로 했습니다.
  - 모서리 근처 부품에 닿으면 홈을 깎거나 알려 주세요.
  - 전원 스위치와 USB는 OpenCR이 커버 안에 있어 손이 닿지 않습니다. 외부 스위치를 달거나, 다음 버전에서 뒤 커버에 구멍을 내겠습니다.
- **Inventor 확인:** Inventor에서 직접 열어 보지는 못했습니다.
