# 키토루 v17 MuJoCo 2단계 검사 결과 (2026-11-26)

이 문서는 키토루 v17 MuJoCo 모델(`model/kitoru_v17.xml`)로 한 2단계 검사를 정리합니다. 모델과 1단계 점검은 `gates/gate_log.txt` 에 있습니다.

- **검사 대상**
  - 설계 코드가 계산한 서보 부하가 물리 시뮬레이션에서도 나오는지
  - 계획한 걸음이 실제 물리에서 어떻게 움직이는지
  - 다리끼리 부딪히는지, 넘어질 때 어디가 먼저 닿는지
- **이번에 하지 않은 것:** 걷는 제어기는 만들지 않았습니다.
- **수치 출처 표기:**
  - [시뮬 실측]: MuJoCo 4.0.1 계산
  - [설계 파일]: code_v17 의 값이나 그 코드를 다시 돌린 값
  - [추정]: 근거가 약한 가정값
- **다시 돌리는 법:** `cd sim && uv run python tests/<스크립트>` 입니다. 결과는 `results/` 에 json 과 그림으로 남습니다.

## 1. 한 일

| 검사 | 스크립트 | 무엇을 했나 |
|---|---|---|

| 7 일어나기 (참고) | `tests/test7_getup_pushup.py` | 엎드린 자세에서 팔을 0 → −120° 로 6초에 걸쳐 천천히 돌려 상체를 밀어 올리고, 그때의 어깨 토크를 봅니다. |

**검사 2의 역동역학 방법**
- 매 시점 디딤발이 영점 자리에 평평하게 놓이도록 몸통 자세를 정기구학으로 풀었습니다.
- 속도와 가속도는 중앙 차분으로 구했습니다.
- `mj_inverse` 는 접촉·등식·한계를 모두 끈 복사본에서 돌렸습니다.
- `qfrc_inverse` 의 몸통 6자유도 성분은 디딤발 몸체 자코비안으로 「바닥이 디딤발에 주는 힘과 모멘트」로 바꿨습니다(J^T w). 나머지 성분이 관절 토크입니다.
- 이렇게 하면 servo_study 의 가정(디딤발은 바닥에 평평히 고정)과 같아집니다.
- 정확도 [시뮬 실측]:
  - 관절각과 몸통 위치가 servo_study 와 1e-13 mm 수준으로 같습니다.
  - 압력중심은 servo_study 의 ZMP 와 0.15 mm 이내로 같습니다.

## 2. 검사별 결과

### 2.1 사용률 최종 표 (검사 1 + 2)

- **조건:** walk + fast + 정지 자세 3개 + 상체 흔들기입니다. servo_opt 와 같은 기준이라 jog 는 빼고 따로 적었습니다.
- **u 의 뜻:** u = |τ|/정지토크 + |ω|/무부하속도 이고, 1 을 넘으면 서보가 못 냅니다.
- **두 가지 서보 값:**
  - 인계 표 값: XC 1.75 N·m, XL 5.45 rad/s
  - e-manual 값: XC 1.7 N·m, XL 5.97 rad/s
- **「+ 회전자 관성」의 뜻:** 모델의 armature 를 넣었을 때입니다. XM 0.045 는 menagerie 값이고, XC 0.0217 은 [추정] 입니다.

## 5. 강화학습에 이 MJCF 를 쓸 때 주의점
1. **kp 와 armature 는 무작위로 바꿔 가며 학습하세요.** 결과가 이 두 값에 가장 크게 달라집니다. 예를 들어 kp ×1–4, XM armature 0.01–0.05 를 고려하세요. 패드 solref·마찰도 넓게 바꾸는 것이 좋습니다.
2. **실제로 쓸 수 있는 고관절 요 범위는 다른 다리 자세에 따라 달라집니다.**
   - 모델은 발·정강이·발목 링크 사이 충돌을 계산합니다(비트 4).
   - 그래도 보상이나 관절 범위로 「두 요 각의 차이」를 제한하는 편이 안전합니다. 한쪽만 돌릴 때 −9 ~ +16° 입니다.
3. **몸통·머리 충돌 형상은 실제보다 큽니다.** 넘어짐 판정이나 접촉 보상에 쓸 때 고려하세요.
4. **손 날개는 0° 고정이고, 머리·귀는 크랭크를 따라 움직이는 수동 관절입니다.** 관측에서 수동 관절은 빼거나 크랭크 각으로 대신하세요.
5. **서보 한계:**
   - 액추에이터 힘 제한이 정지토크로 걸려 있습니다(forcerange).
   - 그러나 속도 한계(무부하속도)는 감쇠로만 근사했습니다. 보상에서 u 를 직접 벌점으로 주는 것을 권합니다.
6. **시작 자세와 시간 간격:**
   - 시간 간격은 1 ms 입니다. 등식 solref 0.002 가 이 값에 맞춰져 있으니 timestep 을 키우면 solref 도 늘려야 합니다.
   - 키프레임 `zero` 는 패드 바닥이 정확히 z = 0 인 자세입니다.
7. **XC430 정지토크 1.75 는 인계 문서 값입니다.** e-manual 은 1.7 이라 보수적으로 잡으려면 1.7 을 쓰세요.

### 7.4 남은 문제
1. **v18 범위(±20°) 안에서도 18개 자세가 겹칩니다.**
   - 모두 발이 엉덩이 바로 아래에 있지 않은 자세입니다. 무릎 30–60° 를 굽혔는데 고관절 피치로 맞추지 않아 발이 뒤로 빠진 자세들입니다.
   - 이때 요 축이 발 중심에서 떨어져 있어, 작은 요로도 발이 옆으로 크게 휩쓸립니다. 발을 깎아서는 막을 수 없습니다.
   - 강화학습에서는 「발이 요 축 아래에 있을 때만 요를 쓴다」는 제한이나 다리끼리 충돌 벌점이 필요합니다. MJCF 는 발·정강이·발목 링크 사이 충돌을 계산합니다.
2. **웅크림 40 mm 이상에서는 발끝 쪽 요가 18° 까지만 안전합니다.** 정강이 껍데기(무릎 앞)끼리 18° 3.25 mm, 20° 1.7 mm 입니다. 정강이 껍데기는 이번 범위가 아니라 그대로 두었습니다.
3. **패드 볼록 껍질이 11.8 % 줄었습니다.**
   - 압력중심이 패드 껍질 밖인 시간이 16.7 → 25.6 %(walk) 로 늘었습니다.
   - 실제로 바닥에 닿는 것은 패드라서, 이 수치가 발바닥 기준보다 실제 지지에 가깝습니다.
   - 안쪽 가운데(x ≈ ±20, y_in ≈ 27)에 패드를 하나씩 더하면 압력중심이 지나가는 안쪽을 덮을 수 있습니다. 소유자 결정이 필요합니다.
4. **열린 고리 걸음의 전진 거리가 200 → 179 mm 로 줄고, 몸통 요 표류가 최대 10 → 16° 로 늘었습니다.**
   - 넘어지지는 않았습니다.
   - 안쪽 패드가 바깥으로 옮겨 발 비틀림을 덜 잡아 주는 탓으로 보입니다 [추정].
5. **공차 미반영:** 큐비콘 PLA(노즐 0.4 mm) 공차는 다음 단계입니다.
