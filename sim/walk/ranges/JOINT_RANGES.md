# 키토루 관절 이동 범위 · 안전 범위 초안 (v19, 2026-11-26)

이 문서는 소유자 요청(2026-11-26)에 답합니다. 요청은 「관절마다 최대로 움직일 수 있는 범위를 파악하고, 나중에 안전 범위를 정할 수 있게」였습니다.

모든 범위는 **v19 설계 형상**에서 나왔습니다(`code_v17/build19.py`, `sim/model/kitoru_v19.xml`). 안전 범위는 **초안**이고, 확정은 소유자가 합니다.

- **수치 출처 표기:** [설계 형상] 설계 solid 정밀 검사, [추정] 근거가 약한 가정
- **판정 방법:** 움직이는 부품의 1.5 mm 격자 점이 다른 부품 solid 안(여유 0.05 mm)에 하나라도 들면 충돌로 봤습니다(`geom4.inside`, `sweep17.py` 와 같은 방식).
  - 영점 자세에서 상대 자세가 바뀐 모든 링크 쌍을 양쪽 방향으로 검사합니다.
  - MuJoCo 부품 볼록 껍질 사이 거리가 1 mm 보다 멀면 그 쌍은 건너뜁니다. 볼록 껍질은 부품을 감싸므로 안전한 거름입니다.
  - 각도는 2° 간격으로 찾은 뒤 반으로 나눠 0.25° 까지 좁혔습니다.
- **충돌로 세지 않은 것**
  - 기구로 원래 맞닿아 움직이는 쌍: 팔 캠 막대 ↔ 혼 어댑터, 손 날개 ↔ 핀, 귀 축 ↔ 베어링
  - 닫힌 고리 막대(nod_rod · ear_rod): 고리 검사(`sweep17.py`)에서 따로 봅니다.
  - 귀 · 크랭크는 머리에 고정했다고 봤습니다(근사).
  - 영점 자세에서 이미 겹치는 부품 쌍(압입 등)은 빼려 했는데, v19 에는 0개였습니다.
- **손 날개:** 팔 각도를 따라 열리게 했습니다(`flap_angle`).
- **다시 돌리는 법 · v20:** 7절에 있습니다.

## 4. Dynamixel 위치 한계 레지스터로 바꾸는 식

- **식:** raw = 2048 + off + d · θ · 4096 / 360
  - θ: 관절각(도, MJCF · joints.csv 부호)
  - d: 회전 방향. 서보 축 방향과 관절 축 방향이 같으면 +1, 반대면 −1 입니다. Drive Mode 의 Reverse 비트로 +1 로 맞출 수도 있습니다.
  - off: 조립 영점 오프셋. 로봇을 영점 자세로 맞춘 뒤 Present Position 을 읽어 off = 읽은 값 − 2048 로 정합니다.
- **레지스터:**
  - d = +1 이면 Min Position Limit(52) = raw(소프트웨어 아래 한계), Max Position Limit(48) = raw(위 한계)
  - d = −1 이면 둘을 바꿉니다.
  - 값은 0–4095 안이어야 합니다. 벗어나면 off 를 다시 잡거나(혼 위치 바꾸기) 확장 위치 모드를 씁니다.
- **예:** 오른 무릎을 d = +1, off = +37 로 조립했다면 Min = 2048 + 37 − 29.0 × 11.378 = 1755, Max = 2048 + 37 + 98.2 × 11.378 = 3202 입니다(11.378 = 4096/360).
- 표의 Dynamixel 열은 off = 0, d = +1 일 때 값입니다. `joint_ranges_v19.csv` 의 `dxl_min_raw` · `dxl_max_raw` 도 같습니다.
- **머리 끄덕임은 수동 관절입니다.** 레지스터는 크랭크 서보(XL430)에 넣습니다. 머리 각 → 크랭크 각은 `sim/model/closed_loop_fit_kitoru_v19.json` 표로 바꿉니다(머리 −10 ~ 20° ≈ 크랭크 −10.8 ~ 20.7°).

## 5. 안전 범위 초안을 쓸 때 주의

- **소프트웨어 한계는 관절 하나만 움직였을 때의 값입니다.** 짝 관절 제한(2절)은 레지스터로 걸 수 없습니다. 제어기나 강화학습에서 따로 걸어야 합니다.
  - 두 요의 차이 −22 ~ +19°(형상 −27 / +24 에서 5° 여유)
  - 무릎 위 한계를 고관절 피치에 따라 줄이기
  - 발목 롤 위 한계를 발목 피치에 따라 줄이기
- **작업 범위**는 소프트웨어 한계 안에서 5° 를 더 뺀 기계적 초안입니다. 걷기에 실제로 쓰는 범위(고관절 피치 −0.8 ~ −0.2 rad, 무릎 0.9–1.3 rad, `../WALK_REPORT.md`)보다 넓습니다. 강화학습 탐색 범위로 쓰면서 줄여 가기를 권합니다.
- **검사 정밀도:** 격자 간격이 1.5 mm 라 실제 첫 접촉보다 최대 약 1 mm 늦게 잡힐 수 있습니다. 3 mm · 5° 여유가 이를 덮습니다.
- **이 검사에 없는 것:** 케이블, 나사 머리, 출력 공차(소유자 경험값 0.1–0.2 mm)

## 7. 다시 돌리는 법 (v20 포함)

```
cd sim/walk
../.venv/bin/python ranges/joint_ranges.py --build build19 --mjcf ../model/kitoru_v19.xml --joints-csv ../../out19/joints.csv --tag v19
uv run python ranges/make_report.py --tag v19 --joints-csv ../../out19/joints.csv
# v20: --build build20 --mjcf ../model/kitoru_v20.xml --joints-csv ../../out20/joints.csv --tag v20
```

- 실행 시간은 약 3분입니다(40개 병렬).
- 관절 목록은 build 모듈의 joints 에서 자동으로 읽습니다(액추에이터 관절 + head_nod). R/L_hip_roll 이 생기면 저절로 들어가고, 「고관절 롤 × 고관절 피치」 지도도 자동으로 더해집니다.
- `--joints` 로 일부만, `--skip pairs,posture` 로 단계를 건너뛸 수 있습니다. 여유는 `make_report.py --margin-deg/--margin-mm/--work-extra-deg` 로 바꿉니다.
